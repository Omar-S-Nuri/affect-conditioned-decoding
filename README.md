# Affect-Conditioned Decoding: Coupling a Lightweight Emotion Estimator to Sampling Parameters in Large Language Models

This repository contains a modular framework for **Affect-Conditioned Decoding**, a method that dynamic-adaptively modulates Large Language Model (LLM) sampling trajectories based on low-cost prompt affect vectors. 

Rather than relying on fixed inference parameters, this framework maps raw text inputs into a 7-dimensional affect space (Valence, Arousal, Dominance, Danger, Resource Value, Social Bond, and Goal Proximity) using a lightweight ridge regression matrix. The resulting vectors alter downstream generation constraints (τ, top_k) in real-time, enforcing behavioral adaptivity (e.g., triggering narrow, deterministic token-selection profiles under high-danger or low-energy metrics).

---

## 🚀 Key Features

* **7D Affect Vectorization:** Low-latency projection of prompt tokens into psycholinguistic and evolutionary survival vectors.
* **🔋 Homeostatic Metabolic Simulation:** Implements a token-dependent energy drain module. Advanced metabolic exhaustion drops generation temperatures to enforce localized, lethargic state processing.
* **🔄 Two-Way Somatic Feedback Loops:** The structural text generated by the Neocortex (LLM) loops back into the physiological controller. Generative tokens describing resting or protection behaviors actively replenish internal energy reserves.
* **🐘 Asynchronous Memory Echoes:** Uses an episodic buffer to let high-stress historical shocks decay sluggishly across subsequent, benign prompts.
* **💡 Active Curiosity System:** Leverages a morphological sub-silbe heuristic to safely forge fallback hypotheses for completely unlearned tokens in RAM.

## 🛠️ Installation & Setup

### Repository File Structure
```text
📁 affect-conditioned-decoding/
├── .env                              # Private API configuration (Local Only)
├── .gitignore                        # Prevents tracking of model weights, cache, and keys
├── LICENSE                           # MIT License
├── README.md                         # Documentation
├── active_curiosity.py               # Handles unseen morphology via character fallback
├── chat_with_pal_final.py            # Live interactive loop with full cognitive feedback
├── evaluate_pal.py                   # 3-Way Ablation Benchmark suite (Perplexity & Distinct-n)
├── expand_lexicon.py                 # Core vector-expansion pipeline via Gemini API
├── finetune_llm_verhaltensvielfalt.py# Fine-tunes the Qwen Neocortex architecture weights
├── hippocampus_memory.py             # Short-term episodic memory dampening module
├── homeostasis_somatic.py            # Metabolic tracking and semantic feedback loops
├── merge_lexicons.py                 # Merges raw psycholinguistic source datasets
├── nrc_final_evolutionary.txt        # Configured 7D target dataset (1400 words)
├── test_model.py                     # Static single-stimulus validator ("tiger" test)
└── train_pal.py                      # Multi-output Ridge model matrix fitter
```

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd affect-conditioned-decoding
   ```

2. **Set up a virtual environment and install dependencies:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Linux/Mac
   ./venv/Scripts/activate   # On Windows
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your private Gemini API key:
   ```env
   GEMINI_API_KEY=your_secret_gemini_api_key_here
   ```

```bash
# 5. Run single-stimulus diagnostic tests (Optional verification)
python test_model.py

# 6. Launch the live interactive system with metabolic feedback loops
python chat_with_pal_final.py

# 7. Run the 3-way ablation evaluation suite to extract LaTeX metrics

```
